# 需求规格说明书 (PRD): 初一数学智能错题本 v2.0

## 1. 项目概述

### 1.1 项目定位
**学习行为改变系统** — 不是错题记录工具,而是通过元认知训练、薄弱点精准诊断和针对性练习,帮助初一学生(12-13岁)改变学习行为、提升数学能力的课外自学系统。

### 1.2 核心用户
- **学生端**: 初一学生,手机端为主,使用场景包括课后复习、错题整理、薄弱点练习
- **家长端**: 数据观察者,查看薄弱点仪表盘和学习行为报告,不干预学习过程

### 1.3 设计理念
- 元认知训练是核心差异化功能,嵌入错题录入和复习唤醒两个关键节点
- 数学能力 = 正确率(40%) + 复习间隔达标率(30%) + 反思质量(30%)
- 游戏化技能地图让薄弱点可视化,同时通过徽章系统提升复习动力

## 2. 技术架构

### 2.1 核心技术栈
| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 框架 | Next.js (App Router), pnpm workspaces | 多包 monorepo 结构 |
| 样式 | Tailwind CSS | 原子化样式,响应式支持 |
| 数学渲染 | KaTeX | 渲染 LaTeX 公式 |
| 存储 | SQLite (本地) | 离线可用,单设备使用 |
| AI 能力 | qwen (通义千问) | OCR、分类、评分、生成 |
| 题库 | SQLite 内置题库 + AI 动态补充 | 混合模式 |

### 2.2 用户体系
- 学生和家长的独立账号,通过**家庭码**关联
- 家长端:纯数据仪表盘,只读,不支持干预操作
- 单设备使用,不支持多端同步

### 2.3 AI 调用策略(阶梯异步)
| 操作 | 策略 | 延迟容忍 |
|------|------|----------|
| OCR 识别 | 实时调用 | < 3s |
| 题目分类 | 实时调用 | < 3s |
| 反思追问生成 | 异步调用(阶梯) | 先展示卡片,后补充追问 |
| 练习题生成 | 异步调用 | 先展示基础题,后台生成变式题 |
| 步骤评分 | 异步调用 | 学生提交后,3-10s 内推送评分结果 |
| 掌握度计算 | 批量计算 | 后台定时更新 |

## 3. 数据结构

### 3.1 静态知识图谱 (data.json)
同人教版初一数学教材,结构如下:
- `chapters[]`: 章节列表
  - `chapter_id`: 章节编码(如 CH01)
  - `title`: 章节标题
  - `sections[]`: 小节列表
    - `id`: 小节ID(如 "1.1")
    - `name`: 小节名称
    - `description`: 知识点定义
    - `key_points[]`: 关键知识点
    - `formulas`: LaTeX 公式(可选)
    - `tags[]`: 标签(如 "数与代数", "几何" )

### 3.2 SQLite 用户数据结构 (练习记录为主轴)

```sql
-- 练习会话表
CREATE TABLE practice_sessions (
  id TEXT PRIMARY KEY,
  student_id TEXT NOT NULL,
  started_at INTEGER NOT NULL,
  finished_at INTEGER,
  target_sections TEXT, -- JSON array of section_ids
  total_questions INTEGER DEFAULT 0
);

-- 题目记录表
CREATE TABLE questions (
  id TEXT PRIMARY KEY,
  session_id TEXT NOT NULL,
  section_id TEXT NOT NULL,
  question_text TEXT NOT NULL, -- OCR或题库提取的文字
  latex_content TEXT, -- LaTeX 公式
  source TEXT NOT NULL, -- 'ocr'|'题库'|'ai_generated'
  question_type TEXT NOT NULL -- '选择'|'解答'
);

-- 作答记录表
CREATE TABLE attempts (
  id TEXT PRIMARY KEY,
  question_id TEXT NOT NULL,
  student_id TEXT NOT NULL,
  answer TEXT NOT NULL, -- 学生作答内容
  is_correct INTEGER, -- 1=正确, 0=错误, NULL=待批改
  step_scores TEXT, -- JSON: {"step1": 3, "step2": 0, "step3": 2}
  ai_feedback TEXT, -- AI 逐行分析反馈
  created_at INTEGER NOT NULL
);

-- 反思记录表
CREATE TABLE reflections (
  id TEXT PRIMARY KEY,
  question_id TEXT NOT NULL,
  error_type TEXT NOT NULL, -- '粗心'|'概念混淆'|'思路断链'|'完全不会'
  card_type TEXT NOT NULL, -- 触发追问的类型
  free_text TEXT, -- 学生自由补充
  created_at INTEGER NOT NULL
);

-- 掌握度表(派生计算,不直接存储)
CREATE TABLE mastery_scores (
  student_id TEXT NOT NULL,
  section_id TEXT NOT NULL,
  accuracy_rate REAL DEFAULT 0, -- 正确率
  review_compliance_rate REAL DEFAULT 0, -- 复习间隔达标率
  reflection_quality_score REAL DEFAULT 0, -- 反思质量评分
  composite_score REAL DEFAULT 0, -- 综合掌握度 0-100
  last_updated INTEGER,
  PRIMARY KEY (student_id, section_id)
);

-- 用户表
CREATE TABLE users (
  id TEXT PRIMARY KEY,
  name TEXT,
  role TEXT NOT NULL, -- 'student'|'parent'
  family_code TEXT NOT NULL,
  created_at INTEGER NOT NULL
);

-- 题目来源表(题库)
CREATE TABLE question_bank (
  id TEXT PRIMARY KEY,
  section_id TEXT NOT NULL,
  difficulty TEXT NOT NULL, -- '简单'|'中等'|'困难'
  question_text TEXT NOT NULL,
  latex_content TEXT,
  answer TEXT NOT NULL,
  solution TEXT NOT NULL, -- 详细解析
  solution_steps TEXT, -- JSON array: 分步解答
  question_type TEXT NOT NULL -- '选择'|'解答'
);
```

### 3.3 掌握度计算算法

```
综合掌握度 = 正确率×40% + 复习间隔达标率×30% + 反思质量评分×30%

- 正确率: 该 section 最近20题的作答正确率
- 复习间隔达标率: 在艾宾浩斯遗忘临界点前完成复习的比例
  (临界点: 1天后、3天后、7天后、14天后、30天后)
- 反思质量评分: 根据反思卡片的填写质量评分
  (只选卡片不填文字=60分, 有具体描述=80-100分, 空着=-20分)
```

## 4. 功能模块详细说明

### 4.1 冷启动模块

**流程**:
1. 学生注册账号,输入基本信息
2. 完成快速能力自测(每章节1道中等难度题,共约10道,预计5-8分钟)
3. 系统计算初始掌握度基线
4. 展示知识地图,学生浏览并做主观确认(对感知较弱的章节点击标记)

**目的**: 建立初始数据,避免从零开始时系统无数据可分析。

### 4.2 错题录入模块 (核心)

**录入方式**:
- 阶段一:单题拍照 OCR,学生确认文字和公式
- 阶段二:整页拍照,AI 自动切分出多道题目,学生逐题确认

**OCR 流程**:
1. 用户拍照/上传图片
2. AI 识别文字内容和 LaTeX 公式
3. 学生确认/修正识别结果
4. AI 根据识别内容和 data.json 进行知识点分类匹配
5. 学生确认分类(可手动调整)
6. 进入反思流程

**反思流程(做错后,做错即触发)**:
1. 系统首先识别错误类型:粗心/概念混淆/思路断链/完全不会
2. 根据错误类型,AI 生成针对性追问
3. 学生通过**选择卡片**定位思维卡点方向
4. 学生通过**补充文字**描述具体卡点
5. 若 AI 分类失败,展示标准四问法兜底:
   - "你在这道题的哪个步骤卡住了?"
   - "当时你是怎么想的?"
   - "你现在知道正确的思路是什么吗?"
   - "下次遇到类似题你会怎么做?"

**公式输入**:
- 提供公式卡片面板,点击插入结构化公式($\sqrt{a}$, $\frac{a}{b}$, $|a|$, $\parallel$ 等)
- 高级模式支持直接编辑 LaTeX 语法,实时预览

### 4.3 薄弱点诊断引擎

**识别逻辑**:
- 每个 section 的综合掌握度由多因子模型计算
- 低于60分标记为"关注",低于40分标记为"薄弱"
- 错误类型分析:AI 读取反思文本,归类为"粗心/概念混淆/思路断链/完全不会"

**输出**:
- 薄弱章节列表(按分数排序)
- 错误类型分布(饼图)
- 每个薄弱章节的典型反思案例

### 4.4 智能练习生成模块

**练习题来源**:
- 优先从 SQLite 题库匹配该 section 的题目
- 题库无匹配时,调用 AI 实时生成变式题

**练习形式**:
- 以解答题为主,AI 步骤级评分
- 选择题用于概念辨析类知识点

**练习流程**:
1. 学生选择或接受系统推送的薄弱章节练习
2. 展示知识点简介(从 data.json description 读取)
3. 展示练习题(优先题库,题库无则 AI 生成)
4. 学生在文本框/公式编辑器作答
5. 提交后 AI 异步评分:
   - 分步得分:展示每一步的对错
   - 逐行分析:AI 指出具体哪一步思路对了/错了
6. 展示变式题(异步生成):后台基于同一知识点生成一道变式题

**复习前唤醒(间隔复习触发)**:
- 在遗忘临界点前,系统推送复习提醒
- 学生点击提醒后,展示该章节历史错题
- 触发反思唤醒:"你现在能独立做出来吗?还记得当时为什么错吗?"

### 4.5 学习画像可视化

**学生端 — 知识地图**:
- 技能树热力图:每个 section 根据掌握度着色
  - 绿色:综合掌握度 ≥ 70
  - 黄色:综合掌握度 40-70
  - 红色:综合掌握度 < 40
- 点击薄弱章节直接进入练习
- 进度条:显示每个 chapter 的总体完成度
- 徽章系统:达成特定里程碑时解锁徽章
  - "首次及格"、"连续7天复习"、"薄弱章节清零"等

**家长端 — 三维度仪表盘**:
- 首页:展示最关键的1-2个指标(如本周薄弱点数量 + 复习完成率)
- 章节掌握度视图:各章节分数列表
- 错误类型分布:柱状图(粗心/概念混淆/思路断链/完全不会)
- 学习行为报告:错题频率、复习完成率、反思质量趋势

**渐进式披露**:家长端首页不堆砌全部数据,点击"查看详情"展开各维度。

### 4.6 提醒与驱动系统

**双触发提醒机制**:
- 遗忘临界点触发:根据艾宾浩斯曲线,在记忆临界点前推送复习提醒
- 薄弱积累触发:当某 section 新增3道以上错题时,触发一轮练习提醒

**提醒形式**:
- 推送通知(需要 PWA 支持或浏览器通知)
- 仪表盘小红点

### 4.7 知识图谱浏览页 (/knowledge-base)

**功能定位**:
- 展示人教版初一数学知识图谱(来自 data.json)
- 每个 section 显示:名称、描述、关键知识点、公式
- 直接显示该学生在该 section 的掌握度分数
- 点击薄弱章节直接进入练习界面

## 6. AI 提示词规范

### 6.1 分类 Prompt
```
根据提供的题目文本,从以下 JSON 知识图谱中选择最匹配的 section id,并给出理由。

知识图谱: {data_json}
题目: {question_text}

请返回 JSON 格式:
{
  "matched_section_id": "1.2",
  "confidence": 0.85,
  "reason": "题目涉及绝对值概念,与 section 1.2 '有理数' 匹配"
}
```

### 6.2 生成 Prompt
```
参考以下知识点的定义,生成一道难度级别为"中等"的初一数学练习题。

知识点: {section_description}
关键点: {section_key_points}

要求:
- 题目必须是解答题(非选择题)
- 输出 JSON 格式,包含:
  - question: 题干(含 LaTeX 公式用 $...$)
  - answer: 完整答案
  - solution_steps: 分步解答的步骤列表
  - solution: 详细解析
  - difficulty: "中等"
```

### 6.3 步骤评分 Prompt
```
请对以下初一数学解答题进行步骤级评分。

题目: {question_text}
学生作答: {student_answer}
标准答案及分步解答: {solution_steps}

评分标准:每个关键步骤分配分数,步骤正确得满分,步骤错误得0分。
步骤部分正确可给部分分。

请返回 JSON 格式:
{
  "total_score": 8,
  "max_score": 10,
  "step_results": [
    {"step": 1, "description": "去括号", "score": 3, "max": 3, "feedback": "正确"},
    {"step": 2, "description": "移项", "score": 2, "max": 4, "feedback": "移项符号错误"},
    {"step": 3, "description": "合并同类项", "score": 3, "max": 3, "feedback": "正确"}
  ],
  "overall_feedback": "在移项步骤出现问题,符号从正变负时漏写了负号。"
}
```

### 6.4 反思追问 Prompt
```
基于以下信息,生成针对性的反思追问。

题目: {question_text}
错误类型: {error_type} (粗心/概念混淆/思路断链/完全不会)
学生当前反思: {current_reflection}

要求:
- 根据错误类型选择最合适的追问方向
- 追问应该是开放式问题,引导深度思考
- 每次追问只提1个问题
- 问题要具体,不要泛泛而谈
- 追问语言适合12-13岁学生理解
```

## 7. 元认知训练设计

### 7.1 核心框架
元认知训练是本系统的差异化核心,嵌入两个关键节点:

**节点1: 做错后反思(即时)**
- 触发条件:学生提交错题后
- 流程:选择错误类型卡片 → AI 生成针对性追问 → 学生填写反思卡片
- 目的:强制学生记录"当时怎么想的",打破自动化错误习惯

**节点2: 复习前唤醒(间隔)**
- 触发条件:遗忘临界点到达前,学生点击复习提醒
- 流程:展示历史错题 → 追问"你现在能独立做出来吗?还记得当时为什么错吗?"
- 目的:激活主动回忆,而不是机械重新看一遍

### 7.2 反思卡片类型与追问映射
| 错误类型 | 追问方向 | 示例追问 |
|----------|----------|----------|
| 粗心 | 注意力监控 | "你是在哪一步开始算错的?是从头还是中途?" |
| 概念混淆 | 概念辨析 | "这道题考的是哪个知识点?你能用自己的话说一遍定义吗?" |
| 思路断链 | 步骤还原 | "做到哪一步你卡住了?前面几步你是怎么想到的?" |
| 完全不会 | 知识定位 | "这道题涉及什么知识?你之前见过类似的吗?" |

## 8. 验收标准

### 8.1 公式准确性
- 所有包含 `$` 的 LaTeX 公式必须通过 KaTeX 正常渲染,无乱码
- 公式卡片插入后实时预览正确

### 8.2 闭环性
- 用户点击薄弱知识点 → 系统跳转至该知识点的简介 → 生成相应练习题
- 完整流程必须在3次点击内完成

### 8.3 响应式
- 手机端(375px+):拍照上传、错题浏览、基础练习
- 平板端(768px+):公式输入、解答题作答、家长仪表盘

### 8.4 性能标准
- OCR 识别响应: < 3s
- 页面首次加载: < 2s (3G 网络)
- AI 评分响应: < 10s(异步,学生可先做下一题)

### 8.5 数据准确性
- 薄弱点判定结果可解释:每个分数都有对应的计算依据
- 家长端数据与学生端一致,无数据延迟

## 9. 知识图谱维护机制

### 9.1 扩展流程
1. **AI 发现**:AI 读取用户错题后,分析是否涉及 data.json 中不存在的知识点
2. **建议提出**:若发现新知识点,生成"建议添加"提案,包含 section 名称、描述、关键点
3. **分级提交**:家长/老师可通过家长端提交知识点补充建议
4. **人工审核**:开发者收到提案后,对照教材核实并合并到 data.json

### 9.2 维护优先级
- 优先级1:修复现有章节的描述错误或缺失关键点
- 优先级2:添加现有章节下的变式题库
- 优先级3:扩展新章节(若教材有更新)

## 10. 已知技术风险

| 风险 | 严重程度 | 应对策略 |
|------|----------|----------|
| 手写体 OCR 准确率不足 | 高 | 阶段一只做印刷体,后续专项优化手写识别 |
| AI 步骤评分不稳定 | 高 | 先做参考答案匹配评分,AI 评分作为辅助参考 |
| 反思质量评估主观性 | 中 | 提供"反思质量"的自评选项,作为参考而非绝对依据 |
