# 实现路线图:初一数学智能错题本

## 原则
- **技术验证优先**:最大风险点(POC)必须先验证,再进入功能开发
- **核心闭环优先**:先打通最小可用流程,再补充辅助功能
- **分阶段交付**:每个阶段都能独立运行和验证

---

## Phase 0: 技术验证 (1-2周)

**目标**:验证两个核心技术风险点的可行性

### 0.1 手写体 OCR 验证
**问题**:整页拍照切分的准确性取决于 OCR 能力
**验证方法**:
- 收集10张真实初一数学作业照片(手写)
- 调用 qwen OCR API 测试识别准确率
- 测试 LaTeX 公式识别能力
- **验收标准**:文字识别准确率 ≥ 80%,公式识别 ≥ 70%

### 0.2 AI 步骤评分验证
**问题**:AI 能否对初一数学解答题做可靠的步骤级评分
**验证方法**:
- 准备20道一元一次方程/整式计算的解答题
- 调用 qwen 对学生作答样本(正确/部分正确/错误)进行评分
- 对比 AI 评分与人工评分的一致性
- **验收标准**:AI 评分与人工评分一致率 ≥ 85%

### 交付物
- OCR 验证报告(准确率数据+问题案例)
- AI 评分验证报告(一致性数据+失败案例)
- 决策:是否需要调整技术方案或引入第三方 OCR

## Phase 1: 核心闭环 MVP (4-6周)

**目标**:打通"错题录入 → 薄弱点识别 → 智能练习"的最小闭环

### 1.1 基础设施
- [ ] Next.js 项目初始化 (App Router, pnpm workspaces)
- [ ] Tailwind CSS 配置
- [ ] KaTeX 配置与公式渲染测试
- [ ] SQLite 数据库初始化(建表 SQL)
- [ ] data.json 知识图谱加载

### 1.2 用户体系
- [ ] 学生注册/登录
- [ ] 家长注册/登录
- [ ] 家庭码生成与关联
- [ ] 会话管理(session/cookies)

### 1.3 错题录入(简化版)
- [ ] 单题拍照上传
- [ ] 实时 OCR 文字识别
- [ ] AI 知识点分类匹配
- [ ] 手动修正分类
- [ ] 公式卡片输入面板
- [ ] 错题存储到 SQLite

### 1.4 反思模块(基础版)
- [ ] 错误类型选择卡片(粗心/概念混淆/思路断链/完全不会)
- [ ] 标准四问法兜底
- [ ] 反思文本存储

### 1.5 薄弱点识别(基础版)
- [ ] 基于错误次数的掌握度计算(简化版,暂用纯次数模型)
- [ ] 薄弱章节列表
- [ ] 错误类型分布统计

### 1.6 智能练习(简化版)
- [ ] 题库建设(每章节3-5道解答题,手动录入)
- [ ] 按章节推题
- [ ] 作答输入(文本框,暂不支持分步)
- [ ] 答案比对(参考答案匹配,暂不支持 AI 评分)

### 1.7 基础仪表盘
- [ ] `/` 仪表盘:薄弱章节列表 + 错题数量
- [ ] `/mistakes` 错题列表:按章节过滤
- [ ] `/knowledge-base` 知识图谱浏览(只读,不显示掌握度)

### 交付物
- 可运行的核心 MVP,能够完成:学生录入错题 → 查看薄弱点 → 做练习题

## Phase 2: 差异化功能 (4-6周)

**目标**:实现元认知训练核心功能和游戏化可视化

### 2.1 反思模块(完整版)
- [ ] AI 分类触发追问(根据错误类型生成个性化追问)
- [ ] 追问链:AI 根据学生前一条回答继续追问(限3轮)
- [ ] 复习前唤醒:在遗忘临界点展示历史错题并追问
- [ ] 反思质量评分(简化版:无文字=低,有具体描述=高)

### 2.2 AI 步骤评分(异步)
- [ ] 分步解答题输入(支持多行文本/公式输入)
- [ ] AI 步骤级评分 API
- [ ] 分步得分展示
- [ ] 逐行分析反馈
- [ ] 异步评分队列

### 2.3 智能练习(完整版)
- [ ] AI 生成变式题(基于薄弱知识点)
- [ ] 题库优先 + AI 兜底逻辑
- [ ] 变式题展示(异步加载)

### 2.4 学生端可视化
- [ ] `/knowledge-base` 知识地图:技能树热力图
- [ ] 各章节掌握度着色(绿/黄/红)
- [ ] 点击薄弱章节进入练习
- [ ] 进度条:各 chapter 完成度
- [ ] 徽章系统:首批5个徽章
  - "首次及格"、"连续3天复习"、"薄弱章节减少1个"等

### 2.5 提醒驱动系统
- [ ] 遗忘临界点提醒(基于艾宾浩斯,简化实现)
- [ ] 薄弱积累触发提醒
- [ ] PWA 推送通知(可选,浏览器支持时)

### 2.6 家长端仪表盘
- [ ] `/parent` 三维度仪表盘
- [ ] 章节掌握度列表
- [ ] 错误类型分布柱状图
- [ ] 学习行为报告(复习完成率趋势)
- [ ] 渐进式披露:首页关键指标 + 详情展开

### 交付物
- 完整的元认知训练闭环,学生端游戏化界面,家长端仪表盘

## Phase 3: 体验优化 (2-3周)

**目标**:提升核心体验,减少摩擦,优化性能

### 3.1 错题录入增强
- [ ] 整页拍照 AI 切分(基于 Phase 0 OCR 验证结果)
- [ ] 手写体优化(如 Phase 0 验证通过)
- [ ] LaTeX 公式实时预览优化
- [ ] OCR 识别结果一键修正

### 3.2 掌握度算法升级
- [ ] 升级为多因子综合评分模型
- [ ] 复习间隔达标率追踪
- [ ] 反思质量评分

### 3.3 性能优化
- [ ] AI 调用异步队列优化
- [ ] SQLite 查询优化
- [ ] KaTeX 渲染性能优化
- [ ] 移动端首屏加载优化

### 3.4 知识图谱维护入口
- [ ] 家长端知识点补充建议提交
- [ ] 开发者审核后台(简易)
- [ ] AI 辅助发现新知识点

### 交付物
- 接近生产级别的产品

---

## Phase 4: 题库建设 (持续)

**目标**:扩充题库覆盖,提升练习题质量

### 4.1 题库录入
- [ ] 各章节题库扩充(每章节10+道题)
- [ ] 题目分类:难度标注、类型标注
- [ ] 分步解答录入(支持 AI 步骤评分的结构化数据)

### 4.2 题目质量
- [ ] 题目审核机制
- [ ] 用户反馈收集
- [ ] 错误题目标记与修正

---

## 优先级排序总结

```
Phase 0: 技术验证          [OCR + AI评分]  ← 最高优先级,阻塞所有后续
Phase 1: 核心闭环 MVP      [注册→录入→薄弱点→练习]
Phase 2: 差异化功能        [元认知+游戏化+家长仪表盘]
Phase 3: 体验优化          [整页OCR+算法升级+性能]
Phase 4: 题库建设          [持续进行]
```
